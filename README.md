# Music Library

A Python-based music library application that allows users to import music files, organize songs, and track listening activity.

## Current Features

- Import music and video files
- Store song information
- View the music library
- Save library data using JSON
- Load saved library data
- Track play counts *(planned)*

## Technologies

- Python
- JSON
- Git / GitHub

## Planned Features

- Music playback
- Play count tracking
- Most Played playlist
- Custom playlists
- Graphical user interface
- Automatic song metadata
